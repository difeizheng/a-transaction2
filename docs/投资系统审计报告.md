## 0. 一句话结论

这是一个**工程鲁棒性上游、投资正确性堪忧**的系统。路由/重试/降级/持久化等工程素养扎实，但踩中了量化回测几乎所有经典致命伤——**审计时点的回测收益数字不可信，且风控存在「单轮推满仓 + 真实回撤时熔断不触发」的结构性漏洞**。结论：**在修复 P0 之前，不得用本系统的回测/选股结果做任何真金白银的判断，不得开启自动交易。**

## 1. 五大致命伤（按「会不会亏真钱」排序）

### 致命伤 ① 回测与实盘「两张皮」（最根本）

专业量化铁律：**回测引擎必须复用实盘交易层的全部约束**。本系统恰恰反着。

- **实盘层**（`src/trading/{rules,portfolio,simulator}.py`）实现了：T+1、板块涨跌停门控（主板10%/创业板20%/科创30%）、非对称印花税、最低5元佣金、手数取整。
- **回测层**（`src/backtest/engine.py`）**几乎一个都没复用**：`grep T+1/涨跌停/停牌/slipage` 在整个 `src/backtest/` 零命中。

后果是一组系统性**单向乐观偏差**：

- 涨停板照样能买入、跌停板照样能卖出（`engine.py` `BTStrategyWrapper.next` 用 `data.close[0]` 决策、backtrader 默认 broker 不拒绝一字板）——趋势/突破类策略恰恰最爱在突破日（=涨停日）下单，回测成交、实盘买不到。
- 零滑点 + 无过户费 + 无限流动性（`engine.py:139-168` `run()` 无 `set_slippage`；`AShareCommissionInfo` 只有 commission+stamp_duty）。
- 止损看当日收盘价、次日开盘才成交——跳空被吃掉，实际止损位远比阈值恶劣。

> **投资判断**：一个回测年化 20%、实盘根本无法执行的策略是负资产。回测越漂亮，误导越深。

### 致命伤 ② 数据层「三连击」——所有回测数字失真

1. **前复权(qfq)落库 + `INSERT OR IGNORE` = 复权因子漂移**
   - `fetcher.py:119` `get_daily_bars(adjust="qfq")` 默认前复权；`base_fetcher.py:18-19` 接口默认 qfq；`manager.py:478` 增量更新未透传 adjust。
   - `storage.py:49-55` `daily_bars` 表**无复权因子列**；`upsert_daily_bars`（`storage.py:276-281`）用 `_insert_or_ignore`（`storage.py:18-21`）。
   - qfq 定义：以最新价为基准重算所有历史价 → 每次除权分红历史价都要变。但旧记录插不进去 → 除权日前后出现**虚假跳空** → MA/MACD/动量信号全错。

2. **财务数据无 point-in-time**
   - `storage.py:58-65` `financial_data` 主键 `(code, report_date)`，**只有报告期，无披露日 `ann_date`**。
   - `tushare_fetcher.py:113-115` 主动丢弃 `ann_date`；`tushare_fetcher.py:146-154` 把当前时点 PE/PB/市值硬塞进最新报告期。
   - `compare.py:21` 注释原文承认：「财务数据（报告期）未截断，存在轻微时点偏差，已知局限」——这不是轻微，是用未来信息决策，回测造假头号来源。

3. **幸存者偏差**：`tushare_fetcher.py:47` `list_status="L"`、akshare `stock_info_a_code_name()` 也只返回在市股。回测池无退市股 → 价值/低估值策略收益系统性高估。

> **投资判断**：三条叠加决定——回测收益率、夏普、选股排名，**方向上都不可信**。

### 致命伤 ③ 风控是「伪命题」——限制开仓 ≠ 下行保护

- **回撤算错**（`auto_trader.py:147-158`）：用 `(initial - total)/initial`，这是**累计盈亏不是回撤**。先赚 60 万再亏到 45 万，真实回撤 -25%，这里算 -10%，**15% 熔断不触发**。机构风控必须用 high-water mark（历史峰值）。
- **加仓不扣已有持仓**（`auto_trader.py:280-281`）：`max_amount = total_value * max_position_pct / 100` 不减现有持仓市值 → 上限被击穿。某股已占 12%、上限 20%，应只加 8%，代码加 20% → 实际 32%。
- **同轮多股无联动**（`auto_trader.py:236-238` 循环外取一次快照）：N 只同时触发，每只按 20% 算，N=4 直接满仓。
- **熔断只「暂停开新仓」**（`auto_trader.py:75`）：已深套持仓照旧裸奔，无减仓/清仓分档。

> **投资判断**：一个未校准的 LLM 高置信信号 + 一轮回调，系统可**单轮把仓位推到 100%，并在真实回撤 25% 时仍判定「未触发 15% 熔断」继续开新仓**。

### 致命伤 ④ LLM 决策门是负价值

系统有两条 LLM 路径，评价须分开：

- **路径 B（情绪/宏观展示）**：`sentiment.py`、`macro.py` 由纯函数确定性算分，LLM 只写定性文字、被明确指令「不要输出任何分数」（`llm_analyzer.py:147,199`）。**这是 LLM 在金融场景唯一合理的定位，改造方向正确。**
- **路径 A（LLM 个股买卖决策门）**（`auto_trader.py:222-223`）：必须 `buy_suggestion=="建议买入"` 且 `confidence>=min_ai_confidence` 才下单。但 `confidence` 是 LLM 自报 0-100 数（AI 界公认 notoriously unreliable），`buy_suggestion` 是不可证伪三选一字符串，阈值 `min_ai_confidence=60` 拍脑袋——**全仓无任何代码验证过「高 confidence 建议的实际胜率」**。

附加风险：
- **Prompt 注入面完全敞开**：`advisor.py:283-287`、`llm_analyzer.py:238-241` 把东贷新闻标题原文拼进 prompt，无 system 隔离、无清洗。
- **JSON 解析用 `raw.find("{")`**（`llm_analyzer.py:274-276`）——模型多吐括号就炸，fallback 默认「观望」→ API 抽风 = 系统性永不买入。
- **不同 provider 共用同一阈值**：claude/openai/第三方 MiniMax 自报置信度分布完全不同，切换 provider = 悄悄切换决策行为。

> **投资判断**：**移除测试**——删掉路径 A 让策略筛选直接进风控，系统更快更便宜更安全。LLM 对短期股价预测力学界共识极弱。保留它只为「AI 加持」叙事，代价是真实风险。

### 致命伤 ⑤ 策略层是「90 年代美股指标」堆砌，A 股真 alpha 全缺

- 核心策略是均线/MACD/KDJ/布林（`technical.py`）——A 股 2015 杠杆牛破裂、2017 机构化后大面积失效，系统**未告知用户**。参数（MA60、MACD 12/26/9、KDJ 30）全是 `pandas_ta` 默认值。
- **多因子动量方向可能反了**（`multifactor.py` `momentum_days=20` 正权重）：A 股 1-3 周是反转效应，20 日涨幅正加权 = 赌反转的反方向 = 稳定亏钱。标准截面动量应是 12 月减最近 1 月。
- **无行业中性化**：价值/成长因子行业聚集性强，`max_pe=20` 绝对阈值 = 只选银行地产。
- **A 股已知有效 alpha 全缺**：小市值、北向资金、龙虎榜、业绩预告超预期、限售解禁、打新。讽刺的是 `IndustryLeaderStrategy` 选大市值，与小市值 alpha 方向相反。

> **投资判断**：这不是因子投资，是「指标越多越好」的堆砌。IC/IR 检验、行业中性化、共线性处理、组合优化——一个都没有。一个没有 IC 检验的因子，等于一个没人验证过真假的因子。

## 2. 真正做对的地方（公正评价）

- **多源路由设计清醒**（`source_router.py`）：把「能力缺失 `NotImplementedError`」与「运行时故障」区分对待，session 级切换不跨任务持久化。
- **跨源单位归一化**（`tushare_fetcher.py:99,102`、`tencent_fetcher.py:138`）：千元→元、手→股，注释点明「避免 100 倍差异」。
- **非对称手续费模型方向正确**（`engine.py:27-47` `AShareCommissionInfo`）：自定义 `CommInfoBase` 实现「佣金双边+印花税仅卖出」，超过 backtrader 内置 `setcommission` 能力。
- **选股阶段有显式前视防护**（`compare.py:18-31` `_AsOfProxy`）：K 线截断到决策日，注释写出「前视偏差」意识——比 90% 业余系统强。
- **实盘 T+1 双层防御**（`portfolio.buy` 设 `available=0`，`end_of_day` 解锁，AutoTrader `available<=0` 兜底）。
- **东财限流韧性层**（`fetcher.py:53-96`）：指数退避+抖动重试+线程级硬超时+腾讯备源+socket 兜底。
- **情绪/宏观展示侧的数据驱动改造**（路径 B）：纯函数算分 + LLM 仅润色。

## 5. 战略定位（方案 B）

本系统定位为**研究 / 可视化 / 学习沙盒**，不触碰实盘自动交易闭环：

- 移除 LLM 买卖决策门（路径 A），AI 分析降级为**展示注释**。
- `AutoTrader` 默认 `auto_execute=False`，降级为**信号生成器**：产出「买入/卖出建议报告」，不自动下单。用户审阅后手动执行（或纸面模拟盘）。
- 专注把**数据层正确性 + 回测可信度 + 因子研究 + 展示**做扎实，彻底规避实盘风险。

P0 是两条路线的共同前提——P0 不修，连「研究」都是自欺欺人（基于失真回测的研究，结论是错的）。
